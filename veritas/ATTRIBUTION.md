## Third-party dependencies

RTAMT (BSD-3-Clause) does the STL robustness computation in `runtime/tbt-monitor/`. pyuppaal
(MIT) reads and writes the UPPAAL XML in `formal/bt2automata/`. Gurobi, used by
`synthesis/ltbt/`, and UPPAAL, used to check the generated model, are neither shipped nor
installed by this project; both need the reader's own license. See the README.

## Edits made to the copied files

Only two files were changed, both for paths and both listed here. No algorithm was rewritten and
no "generated by" banners were added.

* `formal/bt2automata/demo.py` — replaces the upstream `bt2ta/main.py`. The composition, the
  declarations, the system instantiation and the two queries are identical, and the generated
  `BT_converted.xml` is byte-identical to the upstream script's output. What changed: the leaf
  template file and the output file are resolved relative to the script rather than the working
  directory, the output path can be given as an argument, and a docstring was added.
* `runtime/tbt-monitor/main.py` — the policy zip and the `videos/` directory are resolved relative
  to the script rather than the working directory, and a `--no-video` flag was added that skips
  the `RecordVideo` wrapper and the moviepy slow-motion pass, so the rollout runs with no display.
  Nothing else changed.

`runtime/tbt-monitor/demo_synthetic.py`, `formal/bt2automata/demo.py`, `tests/` and this
directory's `README.md`, `ATTRIBUTION.md` and `pyproject.toml` were written for this release.
